# El equipo ideal

> En construcción. Esto es un esbozo; el documento completo llega con la feature `team-coach` del cambio `add-equipo-ideal`.

Un **técnico** (orquestador) y hasta **11 jugadores** especialistas, todos subagentes de Claude Code en `.claude/agents/`. El técnico lee el contexto y decide la convocatoria: puede llamar a todos los jugadores o solo a algunos. El `checker` actúa como **árbitro**: es independiente y no forma parte del equipo.
